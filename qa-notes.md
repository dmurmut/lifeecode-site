# Preview QA notes

The desktop rendering at 1440 × 1000 shows a clear author identity within the first viewport, strong editorial hierarchy, a text-only forthcoming-book treatment, consistent deep-teal and warm-ivory contrast, and a distinct but subordinate LifeeCode section. The full page maintains generous spacing and avoids unsupported imagery or publication claims.

The mobile rendering at 390 × 844 preserves readable heading wraps, stacked calls to action, single-column book cards, a compact sticky header, and a responsive newsletter preview. No horizontal overflow or obscured content is visible. The mobile header includes a dedicated accessible menu button; the menu contains the same destinations as the desktop navigation.

The preview intentionally marks the newsletter form as nonfunctional. It does not collect addresses and does not imply that a provider, welcome email, double opt-in flow, privacy policy, or unsubscribe mechanism has already been configured.
