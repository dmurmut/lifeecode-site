# LifeeCode Hindi Distribution Workflow

Use this reference when the user needs help with **publishing, launch packaging, social distribution, or website mentions** for **LifeeCode Hindi**.

## Core Distribution Principle

The primary job of a launch post is to help the listener understand **why this episode matters** and then take the **next obvious action**. For most episode launches, that primary action is **listen now**. The website can be mentioned as a **secondary destination**, not as the dominant call to action.

## Current Product Setup

Treat **LifeeCode Hindi** as a distinct Hindi-first product under the broader LifeeCode ecosystem.

| Item | Current operating standard |
|---|---|
| **Brand structure** | One brand, two labeled streams: English/global LifeeCode and Hindi-first LifeeCode Hindi |
| **Social presence** | Use existing LifeeCode social presence; do not assume separate Hindi-only accounts unless the user explicitly decides to create them |
| **Podcast platform setup** | Prefer a separate Hindi show when a platform supports multiple shows under one creator account |
| **Format priority** | Audio first, with faceless YouTube expansion later if requested |

## Default Publish Cadence

Use this cadence unless the user overrides it.

| Context | Recommendation |
|---|---|
| **Launch episode** | Sunday launch is acceptable when the user wants an auspicious first release |
| **Ongoing cadence** | Publish new episodes on **Tuesday at 8:00 AM IST** |
| **Social promotion** | Publish on the same day as the episode, or shortly before the release when scheduling tools are available |

## Social Posting Strategy

Use the same brand account but clearly label the Hindi stream.

| Platform | Posting role | Style expectation |
|---|---|---|
| **LinkedIn** | Credibility, thoughtfulness, and launch framing | Slightly more reflective, still concise |
| **X** | Curiosity, immediacy, and repeat exposure | Short, sharp, and episode-led |
| **Facebook** | Familiarity and conversational relevance | Slightly warmer and more relatable |

The recommended default for written copy is **Devanagari-plus-Roman**:

- Write Hindi body text in **Devanagari**.
- Keep **LifeeCode** and familiar tech words in **Roman**.
- Keep hashtags mostly in **Roman**.

## Link Strategy

When in doubt, keep the **episode link primary** and the **website secondary**.

| Surface | Default link rule |
|---|---|
| **Episode launch post** | Primary CTA should point to the episode or listening destination |
| **Website mention** | Add `devmmurmu.com` as a secondary brand destination when helpful |
| **Podcast outro** | A short website mention is useful because listeners may remember a simple domain later |
| **Repeat posts** | The website can become more prominent in follow-up or ecosystem-building posts |

A good website-aware closing line is:

> **और LifeeCode के बाकी health-tech content, briefs, और updates के लिए विज़िट करें: devmmurmu.com**

## Already-Posted Content

If the user has **already posted**, do not over-correct. Incorporate the website lightly.

| Platform | Best next step |
|---|---|
| **LinkedIn** | Edit the last line, or add the website in the first comment if the original post is already performing well |
| **X** | If the edit window is gone, add the website through a reply, quote post, or supporting follow-up post |
| **Facebook** | Edit the existing post and append a short website line near the end |

## Social Ratio Guidance

If the user is mixing Hindi and English posts in the same brand feed, use these rough ratios unless new data suggests otherwise.

| Platform | Suggested Hindi mix |
|---|---|
| **LinkedIn** | Around **1 Hindi post per 3–4 English posts** |
| **X** | Around **1 Hindi post per 2–3 English posts** |
| **Facebook** | Around **1 Hindi post per 1–2 English posts** |

Treat these as directional, not rigid. Adjust based on response quality.

## Outro Guidance

The outro should stay short and repeatable. It can include three ideas in light form: the educational boundary, the future-listening cue, and the website cue.

A safe default line is:

> **LifeeCode Hindi सुनने के लिए धन्यवाद. और ऐसे ही privacy-first, evidence-based health-tech content के लिए विज़िट करें devmmurmu.com.**

## What to Avoid

| Avoid | Why |
|---|---|
| Making every post purely about the website | Weakens the episode-launch purpose |
| Overloading posts with multiple links | Splits attention |
| Switching to fully Roman Hindi by default | Breaks the newer Hindi-first written identity |
| Treating LifeeCode Hindi as a translated copy of the English stream | Ignores the product separation and audience difference |
| Sounding like gadget marketing | Weakens the interpretation-first positioning |
