# LifeeCode SEO & YouTube Optimization Guide

## Title Formula

Format: [Primary Keyword] + [Benefit/Hook] + [Year/Update]
Target length: 55-60 characters
Rule: Front-load the primary keyword in the first 3-4 words

**Examples by story type:**

| Story Type | Title Formula Example |
|---|---|
| Privacy/Risk | "Wearable Data Privacy 2026: What Your Tracker Shares" |
| FDA/Regulatory | "FDA Wearables 2026: New Rules That Change Everything" |
| Medical AI | "AI Health Monitoring: Is It Actually Accurate?" |
| Longevity | "Biological Age Tracking: Best Methods in 2026" |
| Research Study | "HRV Accuracy Study: What Wearables Get Wrong" |
| Weekly Digest | "Health Tech Weekly: 5 Updates You Need to Know" |

## Spoken Keyword Placement

YouTube transcribes every spoken word. Place keywords naturally in:

- **60-second intro**: Say primary keyword in first 30 seconds
- **Segment 1**: Say secondary keyword once naturally
- **Segment 3**: Say long-tail keyword as a question ("If you're wondering how to...")
- **Segment 5**: Say channel name and website once

Never force keywords — if it sounds unnatural, rephrase.

## Thumbnail Specifications

| Element | Specification |
|---|---|
| Dimensions | 1280 × 720px minimum (1920 × 1080px preferred) |
| Format | JPG, high quality |
| Background | Deep navy `#0A1628` |
| Primary text | White, Montserrat ExtraBold, max 2 lines |
| Accent colour | Amber `#F5A623` |
| Alert colour | Red `#E53E3E` (privacy/risk stories only) |
| Tech graphic | Teal `#00D4D4` (DNA helix, smartwatch, brain) |
