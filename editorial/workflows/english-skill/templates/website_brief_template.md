# LifeeCode Website Brief Template
## Use this format when asked to format 5 updates into a website brief

This template is locked to the preferred Episode 7 structure. Keep the section order stable from week to week. Always include the Privacy Radar table in this format. Evaluate whether to add a Global Signal section each week. Do not include a "What's Next?" section unless the user explicitly asks for it.
