# LifeeCode editorial workspace

Start with `RUNBOOK.md` (the weekly scheduled runs) and `PUBLISHING.md` (how a brief goes on the site).

Not part of the website build. Holds the weekly production workflows and the episode archive used for duplicate screening.

- `workflows/english-master-workflow.md` — current English weekly workflow (faceless-first, eight-file package, no publishing).
- `workflows/older-combined-master-prompt.md` — older combined English + Hindi prompt; Hindi sections still apply.
- `workflows/english-skill/`, `workflows/hindi-skill/` — skill files exported from Manus (29 Oct 2026).
- `archive/` — what survived from Manus: approved English brief PDFs (Episodes 8, 9, 11, 12), structured brief data, Hindi Spotify archive (Episodes 1–10).
- `archive/episode-index.md` — every known English and Hindi episode title; the duplicate-screen baseline.
- `episodes/` — one folder per weekly run from Episode 22 (English) / 20 (Hindi) onward.

Manus's original per-episode folder (/home/ubuntu/lifeeecode_weekly/) no longer exists; Episodes 13–21 (English) and 11–19 (Hindi) are known only by the titles listed in the index.
